# Contributing to DoctorG

Thanks for helping! You can contribute code, translations, detection data, tests or bug reports.

## Ways to help
- Report bugs and false positives (use the issue templates, include phone model, Android version and the "Why?" details)
- Translate strings and scam awareness guides
- Add or improve blocklists, YARA rules, stalkerware entries and trusted-publisher data
- Write tests and test on different phones

## Build
1. Install the latest Android Studio.
2. Clone the repo and open it in Android Studio.
3. Sync Gradle and run on a device or emulator (Android 8.0+).

## Pull requests
1. Fork the repo and create a branch (`feature/your-change`).
2. Keep PRs small and focused; add tests when you can.
3. Describe what changed and how you tested it.
4. Do not commit keystores, API keys or personal data.

By contributing, you agree that your work is licensed under the project license (GPL-3.0).

## Security issues
Please report vulnerabilities privately (see SECURITY.md), not in public issues.
